STEP 1: Install Miniconda (if not already installed)
────────────────────────────────────────────────────────

Check if conda is installed:
  $ conda --version

If not installed, choose ONE of these options:

OPTION A: Homebrew (easiest)
  $ brew install miniconda
  $ conda init bash
  $ exec bash

OPTION B: Direct download (works everywhere)
  $ curl -o ~/miniconda.sh https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-x86_64.sh
  $ bash ~/miniconda.sh -b -p ~/miniconda
  $ rm ~/miniconda.sh
  $ ~/miniconda/bin/conda init bash
  $ exec bash

After installation, verify:
  $ conda --version

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: No module named 'torch'"
Solution: Make sure you:
  1. Created the conda environment: conda create -n hr_dr python=3.10 -y
  2. Activated it: conda activate hr_dr
  3. Installed PyTorch: conda install pytorch -c pytorch -y

Problem: "CUDA out of memory"
Solution: Reduce batch size in config_high_accuracy.py:
  BATCH_SIZE = 8  # Instead of 16

Problem: "Data not found" errors
Solution: Ensure data is organized:
  $ python data_preparation.py

Problem: Training very slow
Solution: Check if using GPU:
  $ python -c "import torch; print(torch.cuda.is_available())"
  If False, training will use CPU (slower but still works)

Problem: Early stopping triggered
Solution: This is not necessarily bad - it means validation accuracy stopped improving.
Check the val_acc from logs - if >90%, the model is good!

KEY FEATURES IMPLEMENTED FOR 95%+ ACCURACY:
═══════════════════════════════════════════════════════════════════════════════

1. ResNet50 Backbone
   - More powerful than EfficientNet for medical imaging
   - Pre-trained on ImageNet for transfer learning
   
2. Larger Input Images
   - 256x256 instead of 224x224
   - Preserves more clinical details
   
3. Advanced Learning Rate Scheduling
   - Warmup phase (5 epochs)
   - Cosine annealing (smooth decay)
   - Minimum learning rate floor
   
4. Conservative Data Augmentation
   - Small crops (90-100%)
   - Limited rotation (±15°)
   - Mild color jitter
   - Appropriate for medical images
   
5. Regularization Techniques
   - Label smoothing (softness=0.1)
   - Dropout (40%)
   - L2 weight decay
   - Gradient clipping
   
6. Training Enhancements
   - AdamW optimizer (better than Adam)
   - Batch size 16 (more updates)
   - 100 epochs with early stopping
   - Best model checkpoint saving

PROJECT SUMMARY:
═══════════════════════════════════════════════════════════════════════════════

Research Question:
  Can an AI model accurately detect and distinguish between Diabetic Retinopathy
  and Hypertensive Retinopathy using fundus images?

Goal:
  Create and test an AI model that identifies HR vs DR differences with >95%
  accuracy using fundus images - exceeding current real-world performance.

Dataset:
  • 4,374 fundus images
  • 3 classes: DR (1,857), Normal (2,161), HR (356)
  • Split: 70% train, 15% val, 15% test

Model:
  • Architecture: ResNet50 (transfer learning)
  • Input: 256×256 RGB images
  • Output: 3-class classification
  • Explainability: GradCAM heatmaps

Performance:
  • Target: 95-98% accuracy
  • Expected per-class F1: 92-97%
