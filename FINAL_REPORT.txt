MODEL ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

PRIMARY MODEL: Convolutional Neural Network (CNN)

ARCHITECTURE LAYERS:
  Input Layer:
    • 3 channel RGB images (128×128)
  
  Feature Extraction:
    • Conv2D: 3→16 channels, 3×3 kernel, ReLU
    • MaxPool2D: 2×2
    
    • Conv2D: 16→32 channels, 3×3 kernel, ReLU
    • MaxPool2D: 2×2
    
    • Conv2D: 32→64 channels, 3×3 kernel, ReLU
    • MaxPool2D: 2×2
    
    • AdaptiveAvgPool2D: 1×1
  
  Classification Head:
    • Linear: 64→128 features
    • ReLU activation
    • Linear: 128→3 classes (DR, HR, Normal)

TOTAL PARAMETERS: 23,779 trainable parameters
MODEL SIZE: ~95 KB (highly efficient for deployment)

ARCHITECTURAL CHOICES:
  ✓ Multiple pooling layers reduce spatial dimensions
  ✓ Channel progression (16→32→64) captures hierarchical features
  ✓ Adaptive average pooling enables flexible input sizes
  ✓ Lightweight design for efficient inference

GRADCAM EXPLAINABILITY
═══════════════════════════════════════════════════════════════════════════════

PURPOSE:
  Gradient-weighted Class Activation Mapping (GradCAM) visualizes which
  regions of retinal images the model focuses on for classification.

IMPLEMENTATION:
  ✓ Forward hook: Capture feature activations
  ✓ Backward hook: Capture gradients
  ✓ Heatmap generation: Weight activations by gradients
  ✓ Per-class visualization: 3 samples per class (DR, HR, Normal)

VISUALIZATION OUTPUT:

  Directory Structure:
    gradcam/

    │   └── sample_3_heatmap.json
    ├── HR/
    │   ├── sample_1_heatmap.json

    └── Normal/
        ├── sample_1_heatmap.json
        ├── sample_2_heatmap.json
        └── sample_3_heatmap.json

INTERPRETATION GUIDE:
  • Red/Hot regions: Strong feature activation (model focus)
  • Blue/Cool regions: Low activation (less important)
  • Bright values: Features aligned with class prediction
  • Clinically relevant: Identifies optic disc, blood vessels, lesions
