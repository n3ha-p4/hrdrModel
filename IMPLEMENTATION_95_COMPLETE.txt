🏗️ TECHNICAL ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════

MODEL ARCHITECTURE:

Input (224×224×3 RGB)
    ↓
ResNet50 Backbone
├─ 4 residual blocks
├─ Skip connections throughout
├─ Batch normalization in each layer
└─ 50 convolutional layers

Classification Head:
    ↓
FC Layer 1: 2048 → 512
├─ Batch Norm
├─ ReLU
└─ Dropout (0.5)
    ↓
FC Layer 2: 512 → 256
├─ Batch Norm
├─ ReLU
└─ Dropout (0.3)
    ↓
Output Layer: 256 → 3
    ↓
Softmax → Class Probabilities

Total Parameters: 24,690,755
Trainable: All (transfer learning on top)


TRAINING PIPELINE:

Data Loading (Batch Size: 32)
    ↓
Data Augmentation (8 techniques):
├─ Rotation (±20°)
├─ Horizontal Flip (50%)
├─ Vertical Flip (50%)
├─ Color Jitter
├─ Affine Transforms
├─ Resizing
├─ Normalization (ImageNet stats)
└─ Total: Up to 8 transforms per image
    ↓
Forward Pass through ResNet50
    ↓
Cross-Entropy Loss Calculation
    ↓
Backward Pass (Gradient Computation)
    ↓
Gradient Clipping (max_norm=1.0)
    ↓
Adam Optimizer Step (with weight_decay=1e-5)
    ↓
Learning Rate Adjustment (Cosine Annealing)
    ↓
Validation on Val Set (every epoch)
    ↓
Best Model Checkpoint (if improved)


METRICS COMPUTATION:

Per-Sample Metrics:
  • Prediction class: argmax(softmax(output))
  • Prediction probability: max(softmax(output))
  • Correctness: pred == truth

Epoch Metrics:
  • Accuracy = Correct / Total
  • Loss (Training) = Mean(CrossEntropyLoss)
  • Loss (Validation) = Mean(CrossEntropyLoss)
  • Learning rate (updated per epoch)

Final Test Metrics:
  • Accuracy: TP+TN / Total
  • Precision (per-class): TP / (TP + FP)
  • Recall (per-class): TP / (TP + FN)
  • F1 (per-class): 2 * Prec * Rec / (Prec + Rec)
  • Confusion Matrix: 3×3 ground truth vs predicted
  • ROC-AUC (if computed)

🚀 HOW TO USE THE TRAINED MODEL
═════════════════════════════════════════════════════════════════════════════

After Training Completes:

Step 1: Verify Model Saved
  ls -lh checkpoints/advanced/best_model.pt
  Expected output: ~150-200 MB file

Step 2: Load for Inference
  ```python
  import torch
  from train_95_resnet import RetinopathyClassifier
  
  model = RetinopathyClassifier(num_classes=3)
  model.load_state_dict(torch.load('checkpoints/advanced/best_model.pt'))
  model.eval()
  ```

Step 3: Make Predictions
  ```python
  from torchvision import transforms
  from PIL import Image
  
  # Load and preprocess image
  image = Image.open('retinal_image.png').convert('RGB')
  transform = transforms.Compose([
      transforms.Resize((224, 224)),
      transforms.ToTensor(),
      transforms.Normalize([0.485, 0.456, 0.406],
                          [0.229, 0.224, 0.225])
  ])
  x = transform(image).unsqueeze(0)  # Add batch dimension
  
  # Get prediction
  with torch.no_grad():
      output = model(x)
      probabilities = torch.softmax(output, dim=1)
      class_idx = torch.argmax(probabilities, dim=1).item()
  
  class_names = ['Diabetic', 'Hypertensive', 'Normal']
  print(f"Prediction: {class_names[class_idx]}")
  print(f"Confidence: {probabilities[0, class_idx].item():.2%}")
  ```
