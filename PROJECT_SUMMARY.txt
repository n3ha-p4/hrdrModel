📊 PROJECT SUMMARY
═══════════════════════════════════════════════════════════════════════════════

Research Question:
  "Can an AI model accurately detect and distinguish between Diabetic Retinopathy
   and Hypertensive Retinopathy using fundus images?"

Goal:
  Develop an AI model achieving >95% accuracy in HR vs DR classification,
  exceeding current real-world performance levels.

Dataset:
  • Total Images: 4,374 fundus photographs
  • Classes: 3-way classification
    - Diabetic Retinopathy (DR): 1,857 images
    - Normal Fundus: 2,161 images
    - Hypertensive Retinopathy (HR): 356 images
  • Split: 70% training, 15% validation, 15% testing

Target Metrics:
  ✓ Overall Accuracy: 95-98%
  ✓ Per-Class Precision: 92-97%
  ✓ Per-Class Recall: 92-97%
  ✓ F1-Score: 0.92-0.97

🎓 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

1. Data Preparation
   Input: 4,374 images in original folders
   Process: Organize into structured train/val/test
   Output: data/organized/train/val/test with class folders

2. Training Loop (100 epochs)
   For each epoch:
     a) Forward pass through all training images
     b) Compute classification loss
     c) Backward pass (gradients)
     d) Optimizer step (update weights)
     e) Validate on validation set
     f) Save best model
   
   Training uses:
     • ResNet50 backbone
     • 256×256 image resolution
     • Batch size 16
     • Cosine annealing learning rate
     • Label smoothing
     • Gradient clipping

3. Evaluation
   Compute metrics on test set:
     • Accuracy, Precision, Recall, F1
     • Confusion matrix
     • Per-class performance

4. GradCAM Visualization
   For test images:
     a) Forward pass to get prediction
     b) Compute gradients w.r.t. conv layer
     c) Generate heatmap of important regions
     d) Overlay on original image


🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "conda: command not found"
Solution:
  • Miniconda not installed
  • Run: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • Then: brew install miniconda

Problem: "ModuleNotFoundError: No module named 'torch'"
Solution:
  • Make sure conda environment is activated
  • Run: conda activate hr_dr
  • Verify: python -c "import torch; print(torch.__version__)"

Problem: "CUDA out of memory"
Solution:
  • Edit: config_high_accuracy.py
  • Change: BATCH_SIZE = 8 (instead of 16)
  • Run: python train_high_accuracy.py

Problem: Training very slow (using CPU instead of GPU)
Solution:
  • Check: python -c "import torch; print(torch.cuda.is_available())"
  • If False, GPU not available
  • Proceed with CPU (slower but will still work)

Problem: "Data not found" errors
Solution:
  • Make sure these exist:
    /Users/neha/Documents/GitHub/hrdrModel/Diabetic Retinopathy Images/DR/
    /Users/neha/Documents/GitHub/hrdrModel/Hypertensive Retinopathy Images/1-Hypertensive Classification/1-Images/1-Training Set/
  • Run: python data_preparation.py

Problem: Early stopping triggered at epoch 30
Solution:
  • This is okay! Means validation accuracy stopped improving
  • Check the displayed best val_acc - if >90%, model is good
  • If <90%, try:
    - Increase NUM_EPOCHS to 150
    - Lower LEARNING_RATE to 2e-4
