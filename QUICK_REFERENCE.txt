# ============================================================================
# INTERPRETING RESULTS
# ============================================================================

Accuracy: Percentage of correct predictions
- Good: >85%
- Excellent: >90%

Precision: Of positive predictions, how many were correct
- Good: >85% per class
- Excellent: >90% per class

Recall: Of actual positives, how many did we find
- Good: >85% per class
- Excellent: >90% per class

F1-Score: Harmonic mean of precision and recall
- Good: >0.85
- Excellent: >0.90

Confusion Matrix: Shows which classes are confused with each other
- Diagonal should be high (correct predictions)
- Off-diagonal should be low (misclassifications)

GradCAM Heatmaps: Red/hot regions = where model focuses
- Good model: Highlights clinically relevant features
- Poor model: May highlight noise or irrelevant regions

1. Data Quality

   - Remove corrupted/duplicate images
