HOW TO USE THE TRAINED MODEL
═════════════════════════════════════════════════════════════════════════════

STEP 1: Load the model
  from model import RetinopathyClassifier
  import torch
  
  model = RetinopathyClassifier(num_classes=3)
  model.load_state_dict(torch.load('checkpoints/high_accuracy/best_model.pt'))
  model.eval()

STEP 2: Prepare input image
  from torchvision import transforms
  from PIL import Image
  
  image = Image.open('retinal_image.jpg')
  transform = transforms.Compose([
      transforms.Resize((128, 128)),
      transforms.ToTensor(),
      transforms.Normalize(mean=[0.5]*3, std=[0.5]*3)
  ])
  input_tensor = transform(image).unsqueeze(0)

STEP 3: Make prediction
  with torch.no_grad():
      output = model(input_tensor)
      probabilities = torch.softmax(output, dim=1)
      predicted_class = torch.argmax(probabilities, dim=1)
  
  class_names = ['Diabetic Retinopathy', 'Hypertensive Retinopathy', 'Normal']
  print(f"Prediction: {class_names[predicted_class.item()]}")

STEP 4: Generate GradCAM visualization
  from gradcam import GradCAM
  
  gradcam = GradCAM(model, model.conv3)
  heatmap = gradcam(input_tensor, class_idx=predicted_class.item())

TROUBLESHOOTING GUIDE
═════════════════════════════════════════════════════════════════════════════

Issue: Model not loading
  Solution: Ensure PyTorch 1.13.1 is installed
  Command: pip install torch==1.13.1

Issue: GradCAM heatmaps not generating
  Solution: Verify model is in eval mode and gradients are enabled
  Code: model.eval() and torch.enable_grad()

Issue: Low accuracy on test set
  Solution: Use advanced model (ResNet50) and extended training
  See: "RECOMMENDED NEXT STEPS FOR 95%+ ACCURACY"

Issue: Image loading errors
  Solution: Ensure images are in RGB format and resizable to 128×128
  Check: Image mode should be 'RGB', not 'RGBA' or 'P'
