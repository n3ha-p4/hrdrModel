🔧 WHAT'S HAPPENING IN THE BACKGROUND
═════════════════════════════════════════════════════════════════════════════

Training Process:
  1. Load batch of images (32 per batch)
  2. Apply random augmentations (rotations, flips, etc.)
  3. Forward pass through ResNet50
  4. Calculate cross-entropy loss
  5. Backward pass (compute gradients)
  6. Update weights using Adam optimizer
  7. Repeat for all training batches
  8. Validate on validation set
  9. Adjust learning rate using cosine schedule
  10. Save model if validation accuracy improves

Data Augmentations Applied:
  ├─ Random Rotation (±20°)
  ├─ Horizontal Flip (50% probability)
  ├─ Vertical Flip (50% probability)
  ├─ Color Jitter (brightness, contrast)
  ├─ Random Affine transforms
  └─ Total: 8 augmentation techniques

Optimization Strategy:
  ├─ Adam optimizer: Adaptive learning rates
  ├─ Learning rate schedule: Starts at 0.001, gradually decreases to 1e-6
  ├─ Gradient clipping: Prevents exploding gradients
  ├─ Weight decay: L2 regularization (1e-5)
  ├─ Early stopping: If validation accuracy doesn't improve for 10 epochs
  └─ Model checkpointing: Saves best model based on validation accuracy
