2. WHAT MAKES THIS DIFFERENT (95%+ STRATEGY)
═══════════════════════════════════════════════════════════════════════════════

BASIC MODEL (33% accuracy - what we had before):
  ├─ Simple CNN with 23K parameters
  ├─ Minimal augmentation
  ├─ 5 epochs training
  └─ No preprocessing

ADVANCED MODEL (95%+ accuracy - target):

  A. ARCHITECTURE IMPROVEMENTS:
     ├─ ResNet50: 25M+ parameters (pre-trained)
     ├─ Feature extraction from ImageNet
     └─ Better pattern learning

  B. DATA AUGMENTATION:
     ├─ Rotations (±20°)
     ├─ Flips (horizontal & vertical)
     ├─ Color jitter (brightness, contrast, saturation)
     ├─ Gaussian blur
     ├─ Affine transforms (scale, translate, rotation)
     └─ Elastic deformations

  C. PREPROCESSING (Scikit-Image):
     ├─ Adaptive histogram equalization (CLAHE)
     │   → Enhances contrast without losing detail
     ├─ Median filtering (denoising)
     │   → Removes noise while preserving edges
     ├─ Morphological operations
     │   → Enhances blood vessel visibility
     └─ Noise reduction with non-local means

  D. TRAINING OPTIMIZATION:
     ├─ Cosine annealing learning rate schedule
     │   → Starts high (0.001), gradually decreases to 1e-6
     ├─ Class weighting (higher weight for HR - minority)
     │   → Balances imbalanced dataset
     ├─ Adam optimizer with weight decay
     │   → Prevents overfitting
     ├─ Gradient clipping
     │   → Stabilizes training
     └─ Early stopping (patience=15)
        → Stops when validation plateaus

  E. TRAINING DURATION:
     ├─ Basic: 5 epochs (~10 seconds)
     ├─ Advanced: 100 epochs (30-60 minutes on CPU)
     └─ → More time = Better convergence

7. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q1: "Training is too slow on CPU"
────────────────────────────────────────────────────────────────────────────
A: This is expected. ResNet50 on CPU takes 30-60 minutes.
   Solutions:
   - Use GPU (if available): CUDA will auto-detect
   - Reduce batch size in train_95_advanced.py (BATCH_SIZE = 16)
   - Reduce epochs (EPOCHS = 50)


Q2: "Out of memory errors"
────────────────────────────────────────────────────────────────────────────
A: ResNet50 uses more memory than simple CNN.
   Solutions:
   - Reduce batch size: BATCH_SIZE = 16 (from 32)
   - Reduce image size: IMG_SIZE = 192 (from 224)
   - Close other applications


Q3: "Accuracy not improving (stuck at ~34%)"
────────────────────────────────────────────────────────────────────────────
A: Model may have data issues or learning rate too low/high.
   Check:
   1. Data preparation: Run 'python3.7 data_preparation.py' first
   2. Data organization: Check data/organized/ exists
   3. Learning rate: Default 0.001 should work


Q4: "Model.pt not loading"
────────────────────────────────────────────────────────────────────────────
A: PyTorch version mismatch.
   Solution: Use same PyTorch version in requirements_95.txt


GETTING HELP:
────────────────────────────────────────────────────────────────────────────

1. Check logs: Look at train output and results/*.txt files
2. Verify data: python3.7 data_preparation.py --verify
3. Try smaller model: Modify architecture in train_95_advanced.py
4. Adjust hyperparameters:
   - Lower learning rate: 0.0001
   - More epochs: 150
   - Smaller batch size: 16
